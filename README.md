This repository contains the completed scripts for Lab 2 of Python Essentials 1.

## Files

- `types_and_vars.py` — demonstrates variables, data types, arithmetic operators, string operations, comments, and formatted output.
- `simple_calculator.py` — accepts two numbers and performs addition, subtraction, multiplication, or division.
- `string_fun.py` — demonstrates string length, uppercase conversion, and string repetition.

## Example Output: types_and_vars.py

```text
Hello, my name is Franky Ndalle. I am 33 years old and 1.75 meters tall.
In 5 years, I will be 38 years old.
I will turn 40 in 7 years.
The area of a 5.5 x 2 rectangle is 11.0.
Python is fun to learn!
--------------------------------------------------
```

## Example Output: simple_calculator.py

```text
Enter the first number: 7
Enter the second number: 3
Choose an operation (+, -, *, /): *
7 * 3 = 21
```

The calculator also supports `+`, `-`, and `/`. It displays an error message for non-numeric input, unsupported operations, and division by zero.

## Example Output: string_fun.py

```text
Enter a word: Python
Length: 6
Uppercase: PYTHON
Repeated three times: Python Python Python
```

## Running the Scripts

Run each script from the terminal with the following commands:

```powershell
python types_and_vars.py
python simple_calculator.py
python string_fun.py
```
